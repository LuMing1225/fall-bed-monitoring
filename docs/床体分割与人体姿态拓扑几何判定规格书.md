## 2. 系统概述

本系统解决跌倒检测中"躺在地上与躺在病床上姿态相似、难以区分"的核心痛点。通过**语义分割**精准定位床体空间，结合**人体姿态估计**提取骨骼关键点，最终通过**拓扑几何算法**实现"在床"与"跌倒"的精确分类。

### 2.1 核心技术栈

| 模块 | 技术方案 | 模型 | 输入 | 输出 |
|------|----------|------|------|------|
| 床体分割 | 语义分割 | MobileSAM (vit_t) | RGB图像 | Bed Mask (二值掩膜) |
| 姿态检测 | 关键点检测 | YOLOv8n-Pose | RGB图像 | 17关键点+边界框 |
| 几何判别 | 规则引擎 | IoU+距离+角度 | Mask+Keypoints | 行为状态标签 |
| LLM纠错 | 时序推理 | Ollama/qwen2.5 | 关键点序列 | 纠错后状态 |

### 2.2 处理流水线

```
视频帧 → [床体分割] → Bed Mask (静态缓存)
              ↓
       [姿态检测] → 17关键点 + 人体边界框
              ↓
       [几何判别] → IoU计算 + 距离度量 + 角度分析
              ↓
       [LLM纠错] → 时序一致性验证 + 漂移纠错
              ↓
         行为状态: Active / On_Bed / Fallen
```

## 3. 床体语义分割规格

### 3.1 模型规格

| 参数 | 规格值 |
|------|--------|
| 模型 | MobileSAM (Segment Anything Model, vit_tiny) |
| 参数量 | ~10M |
| 模型大小 | ~40MB (FP32) |
| 推理设备 | CUDA (优先) / CPU |
| 输入分辨率 | 原始分辨率 (最长边≤1024) |
| 单帧推理时延 | ~30-50ms (GPU) |

### 3.2 分割策略

#### 3.2.1 静态掩膜缓存机制

床体在监控场景中位置固定，采用**静态掩膜缓存**策略：

1. **初始化阶段**: 系统启动后对首帧（或前N帧）执行MobileSAM分割
2. **候选框策略**: 生成4个候选区域（左半床、右半床、整床、中央区域）
3. **评分筛选**: 综合置信度(60%) + 面积合理性(20%) + 位置合理性(20%)
4. **掩膜缓存**: 最优掩膜作为静态Bed Mask缓存
5. **周期刷新**: 每300帧或检测到场景变化时自动重新分割

#### 3.2.2 面积与位置约束

| 约束 | 条件 | 说明 |
|------|------|------|
| 最小面积 | > 500像素 | 过滤噪声掩膜 |
| 面积占比 | 5% - 70% | 床体通常占画面15%-60% |
| 垂直位置 | 中心在画面40%-80% | 床体位于中下部 |
| 宽高比 | 0.5 - 3.0 | 病床通常横向较长 |

### 3.3 床体几何属性

分割完成后，从Bed Mask提取以下几何属性：

```python
bed_contour      # 床体轮廓（最大连通域）
bed_bbox         # 边界框 (x, y, w, h)
floor_edge_y     # 地面边缘y坐标 = bed_bbox.y + bed_bbox.h
bed_area         # 床体面积（像素）
bed_center       # 床体质心
```

**地面边缘定义**: 床体底部边界线，用于区分"在床上"（臀部y < floor_edge_y）与"在地面"（臀部y ≥ floor_edge_y）。

### 4.4 衍生几何量

从17关键点计算以下衍生量：

| 衍生量 | 计算公式 | 用途 |
|--------|----------|------|
| 人体中心 | mean(shoulder_center, hip_center) | 位置定位 |
| 臀部中心 | mean(left_hip, right_hip) | 在床/地面判定 |
| 人体轴线 | hip_center - shoulder_center | 躺卧/站立判定 |
| 轴线角度 | arctan2(|dy|, |dx|) × 180/π | 0°=水平, 90°=垂直 |
| 关键点凸包 | convexHull(valid_keypoints) | IoU计算 |
| 人体边界框 | min/max of keypoints | 区域定位 |

### 4.5 时序处理

#### 4.5.1 目标跟踪

- 基于IoU(70%) + 中心距离(30%)的匹配策略
- 最小匹配IoU阈值: 0.3
- 跟踪过期: 30帧未匹配则删除

#### 4.5.2 关键点平滑

- 滑动窗口: 5帧
- 加权平均: 线性递增权重（越近权重越大）
- 仅对坐标(x,y)平滑，置信度取最大值

#### 4.5.3 漂移纠错

- 单帧最大位移阈值: bbox对角线 × 30%
- 超过阈值的关键点视为异常跳变
- 用前一帧值替代，置信度衰减为80%

## 5. 几何判别规则引擎规格

### 5.1 状态决策方程

**核心决策方程**（工单要求）：

```
           { Active/On_Bed,  if  Kn ∩ Mask_bed / Kn ≥ τ  AND  Y_hip < Y_floor_edge
Status =  {
           { Fallen,          otherwise
```

其中：
- **Kn** = 躯干关键点集合（肩、髋、膝、踝）
- **Mask_bed** = 床体二值掩膜
- **τ** = 面积重合阈值 = 0.5
- **Y_hip** = 臀部关键点y坐标
- **Y_floor_edge** = 地面边缘y坐标

### 5.2 判别特征

| 特征 | 计算方法 | 在床特征 | 跌倒特征 |
|------|----------|----------|----------|
| **IoU** | intersection(person_mask, bed_mask) / union | ≥ 0.5 | < 0.15 |
| **关键点在床比例** | count(kp in bed_mask) / count(valid_kp) | ≥ 0.6 | < 0.3 |
| **臀部相对高度** | Y_floor_edge - Y_hip | > 0 (在地面上方) | ≤ 0 (在地面或下方) |
| **人体轴线角度** | arctan2(|dy|, |dx|) | 任意（坐/躺） | < 30° (接近水平) |
| **到床体距离** | distanceTransform(center, bed_mask) | 0 (在床内) | > 50px |

### 5.3 分类决策逻辑

#### 5.3.1 在床 (On_Bed) 判定

**满足以下至少2/3条件**:

1. **IoU ≥ τ (0.5)**: 人体区域与床体重叠度高
2. **关键点在床比例 ≥ 0.6**: 多数关键点落在床体Mask内
3. **Y_hip < Y_floor_edge**: 臀部在地面边缘上方

**置信度计算**: `0.5 + 0.5 × min(IoU / τ, 1.0)`，上限0.98

#### 5.3.2 跌倒 (Fallen) 判定

**满足以下至少3/4条件**:

1. **人体接近水平**: 轴线角度 < 30°
2. **IoU < 0.15**: 人体不在床上
3. **关键点在床比例 < 0.3**: 关键点几乎都在床外
4. **臀部接近/低于地面边缘**: Y_hip ≥ 0.85 × Y_floor_edge

**置信度计算**: `0.5 + 0.5 × fallen_score`，上限0.99

#### 5.3.3 活动 (Active) 判定

- 人体轴线角度 > 45°（明显站立/坐姿）
- 不满足在床或跌倒条件

#### 5.3.4 未知 (Unknown)

- 过渡状态，置信度 < 0.5
- 关键点缺失过多

### 5.4 时序确认机制

#### 5.4.1 跌倒连续确认

- 跌倒状态需要连续 **3帧** 确认才触发报警
- 未达到连续帧数时，降级为UNKNOWN或保持前一状态
- 防止瞬时误判导致高频误报

#### 5.4.2 状态迟滞

- 最近3帧中多数票状态优先
- 防止状态频繁抖动
- 跌倒状态不受迟滞影响（需要严格确认）

### 5.5 验收标准

| 指标 | 标准 | 测试方法 |
|------|------|----------|
| 躺在床上误报率 | ≤ 2% | test_lie_on_bed_exclusion |
| 跌倒在地上漏报率 | = 0% | test_fall_on_floor_detection |
| 躺在床上分类准确率 | ≥ 98% | 合成场景30帧测试 |
| 跌倒捕获灵敏度 | = 100% | 合成场景30帧测试 |
| 单帧处理时延 | ≤ 30ms | 1080P基准测试 |
| 运行内存占用 | ≤ 1.8GB | GPU显存监控 |

## 6. LLM姿态时序纠错规格

### 6.1 功能定位

模拟 **Llama V2 Pose** 边缘端推理，基于自注意力机制的骨骼关键点时序漂移纠错：

1. 分析连续帧关键点轨迹，检测异常漂移
2. 评估关键点间的时空一致性（自注意力）
3. 对跌倒/在床判别进行二次确认
4. 生成自然语言分析报告

### 6.2 技术实现

| 参数 | 规格 |
|------|------|
| 推理后端 | Ollama (本地) |
| 模型 | qwen2.5:7b (模拟Llama V2 Pose) |
| 时序窗口 | 10帧 |
| 调用条件 | 状态可疑/切换时（节省资源） |
| 超时 | 30秒 |
| 温度 | 0.3 (低随机性) |

### 6.3 纯算法纠错（无LLM时降级）

当Ollama不可用时，使用纯算法纠错：

1. **漂移分数**: 相邻帧关键点位移比（当前/平均），归一化到[0,1]
2. **状态一致性**: 最近5帧同一状态比例
3. **跌倒事件检测**: 臀部y快速增大 + 轴线从垂直变水平（角度变化>20°）

## 7. 不同相机视角下的床体物理轮廓与地面界线规则

### 7.1 正视视角（相机正对病床）

```
相机位置: 病床正前方，高度约1.5m
床体投影: 矩形，上下边水平
地面界线: 床体底部边界线 (Y_floor_edge = bed_bbox.y + bed_bbox.h)
判别规则: 直接使用IoU + Y_hip比较
```

### 7.2 俯视视角（相机在天花板）

```
相机位置: 病床正上方，向下拍摄
床体投影: 矩形，占据画面中央
地面界线: 床体轮廓外侧区域即为地面
判别规则: 
  - 透视变换校正: 将俯视投影转换为侧视坐标
  - 使用Homography矩阵: 4个床角点 → 标准矩形
  - 校正后Y坐标用于高度判断
```

### 7.3 侧视视角（相机在病房侧面）

```
相机位置: 病床侧面，与床长边平行
床体投影: 梯形（近大远小）
地面界线: 床腿底部连线（透视汇聚线）
判别规则:
  - 床体Mask使用梯形轮廓而非矩形
  - 地面边缘需要透视校正: Y_floor_edge = 透视变换后的床底线
  - 臀部高度需要结合深度信息校正
```

### 7.4 透视变换校正方程

对于非正视视角，使用**单应性矩阵(Homography)**进行校正：

```
设床体4个角点在图像中为: P1, P2, P3, P4 (顺时针)
目标标准矩形角点为: Q1(0,0), Q2(W,0), Q3(W,H), Q4(0,H)

求解单应性矩阵 H (3x3):
  Q = H × P  (齐次坐标)

校正后坐标:
  [x', y', 1]ᵀ = H × [x, y, 1]ᵀ
  X_corrected = x' / w'
  Y_corrected = y' / w'

使用校正后的Y坐标进行在床/地面判别:
  On_Bed  if  Y_corrected_hip < Y_corrected_floor_edge
```
